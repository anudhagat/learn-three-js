# learn-three-js

Projects for learning three.js and React Three Fiber. Each folder is its own app, with
its own `package.json`, so you run it from inside the folder.

| Project | What it is |
| --- | --- |
| [`bouncy-emoji-ball`](bouncy-emoji-ball) | An emoji ball that bounces, falls asleep and plays with candy on a dusk meadow. |

Run a project:

```sh
cd bouncy-emoji-ball
npm install
npm run dev
```
